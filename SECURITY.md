# Security policy

## Supported versions

Security fixes are made for the latest release. Please update before reporting.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately through GitHub's [private vulnerability reporting](https://github.com/SomeCatCode/nextcloud_ebook_reader/security/advisories/new) instead.

Include the app and Nextcloud version, steps to reproduce, and (if possible) a sample file. Malicious e-books and archives are especially relevant: the reader treats book content as untrusted, see [docs/SECURITY-READER.md](docs/SECURITY-READER.md).

You will get an answer as soon as possible; fixes are released and credited in the changelog unless you prefer otherwise.
